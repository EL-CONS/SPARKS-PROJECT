Análisis detallado de los recursos del reto

 IRSA SPHEREx

Enlace: [[https://irsa.ipac.caltech.edu/Missions/spherex.html][IRSA SPHEREx]]

Datos o herramientas que da: Archivo oficial de datos SPHEREx (niveles 1, 2 y 3), catálogos asociados (SPLICES), herramientas de acceso como SIA2, TAP (ObsTAP), cutouts IBE y visores web (SPHEREx Data Explorer, Spectrophotometry Tool, Mosaic Tool, Source Discovery Tool, MOST). [VERIFICADO]

Cómo se accede: Vía API SIA (Cone Search / ObsTAP), solicitudes HTTP directas a IBE cutouts, o mediante librerías de Python como =astroquery= y =pyvo=. [VERIFICADO]

Reglas de uso o límites: Límites de tasa (rate-limiting) y políticas de servicio de IPAC/Caltech [sin verificar límites exactos de peticiones por segundo]; la misión y los datos públicos de la NASA se rigen por las condiciones de uso de datos abiertos de IPAC. [VERIFICADO]

Dónde encaja en Sparks: Núcleo absoluto del backend para la ingesta de imágenes MEF nivel 2, consulta de metadatos, banderas y obtención de cutouts bajo demanda. [INFERENCIA]

 Tutoriales de SPHEREx

Enlace: [[https://caltech-ipac.github.io/irsa-tutorials/spherex/][Tutoriales]]

Datos o herramientas que da: Notebooks oficiales en Python que explican la introducción a los datos, cómo realizar cutouts mediante consultas TAP (=spherex.artifact JOIN spherex.plane=), cómo manejar el cubo PSF y WCS espectral (=key='W'=), y el uso de acceso en la nube S3. [VERIFICADO]

Cómo se accede: Descarga o clonación del repositorio de GitHub ([[https://github.com/Caltech-IPAC/irsa-tutorials][Caltech-IPAC/irsa-tutorials]]). [VERIFICADO]

Reglas de uso o límites: Código abierto bajo licencia de IPAC/Caltech; se recomienda configurar =astropy.utils.data.conf.remote_timeout = 120= debido a la latencia de las consultas al archivo. [VERIFICADO]

Dónde encaja en Sparks: Guía técnica y base de código para estructurar las peticiones asíncronas y el procesamiento backend en el equipo de desarrollo. [INFERENCIA]

 WiseView

Enlace: [[http://byw.tools/wiseview][WiseView]]

Datos o herramientas que da: Visor web interactivo especializado en animaciones temporales (flipbooks) de datos unWISE/WISE para ciencia ciudadana (Backyard Worlds). Permite parpadear épocas, ajustar contraste, velocidad y marcar objetos móviles. [VERIFICADO]

Cómo se accede: Aplicación web pública en línea ([[http://byw.tools/wiseview][WiseView]]). [VERIFICADO]

Reglas de uso o límites: Aplicación web externa de uso público sin API directa de integración (modelo UX de referencia). [VERIFICADO]

Dónde encaja en Sparks: Referencia fundamental de UX/UI para el diseño del visor de flipbooks en el frontend (cómo debe sentirse visualmente el parpadeo temporal y la inspección de movimientos). [INFERENCIA]

 Gaia en STScI

Enlace: [[https://archive.stsci.edu/missions-and-data/gaia][Gaia en STScI]]

Datos o herramientas que da: Catálogos astronómicos de alta precisión de la misión Gaia (Data Release 3), incluyendo posiciones celestes absolutas, paralajes y vectores de movimiento propio (PMRA, PMDec). [VERIFICADO]

Cómo se accede: Archivo STScI, servicios TAP de la ESA o VizieR (=gaia_dr3_source=). [VERIFICADO]

Reglas de uso o límites: Sujeto a disponibilidad de los servidores de la ESA/STScI (en pruebas, el TAP de ESA dio error 503 por saturación y las consultas en IRSA superaron los 250s, por lo que requiere precálculo). [VERIFICADO]

Dónde encaja en Sparks: Capa superpuesta en Aladin Lite 3.8.2 y validación cruzada del movimiento propio medido en SPHEREx contra la verdad de terreno astrométrica. [INFERENCIA]

 NEOSSat (Agencia Espacial Canadiense - CSA)

Enlace: [[https://www.asc-csa.gc.ca/eng/satellites/neossat/][NEOSSat]]

Datos o herramientas que da: Satélite en órbita terrestre dedicado a la detección de asteroides cercanos (NEO) y basura espacial en el espectro óptico visible. [VERIFICADO]

Cómo se accede: Portal institucional de la CSA ([[https://www.asc-csa.gc.ca/eng/satellites/neossat/][NEOSSat]]). [VERIFICADO]

Reglas de uso o límites: Datos espaciales de una misión canadiense de órbita baja y espectro óptico. [VERIFICADO]

Dónde encaja en Sparks: No aporta nada real a nuestra herramienta y es solo contexto. Razón: El reto se centra exclusivamente en el archivo infrarrojo de SPHEREx (NASA), mientras que NEOSSat opera en el óptico para objetos cercanos, sin relación con el pipeline ni los formatos de datos de SPHEREx. [INFERENCIA]

 CADC (Canadian Astronomy Data Centre)

Enlace: [[https://www.cadc-ccda.hia-iha.nrc-cnrc.gc.ca/en/][CADC]]

Datos o herramientas que da: Centro de datos astronómicos de Canadá, archivo general de múltiples misiones espaciales y terrestres (incluyendo NEOSSat). [VERIFICADO]

Cómo se accede: Portal web institucional ([[https://www.cadc-ccda.hia-iha.nrc-cnrc.gc.ca/en/][CADC]]). [VERIFICADO]

Reglas de uso o límites: Repositorio general de astronomía de Canadá. [VERIFICADO]

Dónde encaja en Sparks: No aporta nada real a nuestra herramienta y es solo contexto. Razón: El archivo oficial de SPHEREx se hospeda íntegramente en IRSA/IPAC (NASA), por lo que CADC no forma parte de la arquitectura de datos del proyecto. [INFERENCIA]

 Tutorial NEOSSat

Enlace: [[https://github.com/asc-csa/NEOSSAT_Tutorial][Tutorial NEOSSat]]

Datos o herramientas que da: Cuadernos y guías para el análisis de datos de la misión NEOSSat. [VERIFICADO]

Cómo se accede: Repositorio en GitHub ([[https://github.com/asc-csa/NEOSSAT_Tutorial][Tutorial NEOSSat]]). [VERIFICADO]

Reglas de uso o límites: Licencia de código abierto de la CSA. [VERIFICADO]

Dónde encaja en Sparks: No se usa. Razón: Al no integrar NEOSSat en la herramienta, sus tutoriales no aplican al desarrollo. [INFERENCIA]

 Dataset NEOSSat

Enlace: [[https://data.asc-csa.gc.ca/dataset/neossat][Dataset NEOSSat]]

Datos o herramientas que da: Conjunto de datos abiertos de la misión NEOSSat. [VERIFICADO]

Cómo se accede: Portal de datos abiertos de Canadá ([[https://data.asc-csa.gc.ca/dataset/neossat][Dataset NEOSSat]]). [VERIFICADO]

Reglas de uso o límites: Términos de datos abiertos de la administración canadiense. [VERIFICADO]

Dónde encaja en Sparks: No se usa. Razón: Fuera del alcance del reto de SPHEREx. [INFERENCIA]
